CSS Removal Log (Assignment 3 - Frau Muller Web Project)
======================================================================
В рамках перехода на Bootstrap 5.3 избыточный ручной CSS из Assignment 2 был удален
и заменен на нативные классы и компоненты фреймворка.

======================================================================
1. Общие стили (css/base.css)
======================================================================
- Удалено: Ручной flexbox для навигации (nav ul { display: flex; gap: 20px; ... })
  Заменено на: Нативный компонент .navbar .navbar-expand-lg с кнопкой .navbar-toggler.

- Удалено: Ручное ограничение ширины и центрирование контента (main { max-width: 1000px; margin: 30px auto; })
  Заменено на: Сетку и контейнеры Bootstrap (.container, .container-fluid, .row).

- Удалено: Ручные сбросы отступов и блочной модели (* { box-sizing: border-box; margin: 0; padding: 0; })
  Заменено на: Встроенный Reboot и нормализацию стилей Bootstrap 5.
