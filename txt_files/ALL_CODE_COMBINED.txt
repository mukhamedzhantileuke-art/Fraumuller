## 3. Three User Journeys (End-to-End Walkthroughs)

Every journey described below can be performed completely and independently by a single visitor using their screen, with no dead ends, no `href="#"`, and with clear completion:

### 🚶 Journey 1: "Найти адрес, режим работы и забронировать столик на вечер"
1. **Start:** Посетитель заходит на главную страницу (`index.html`), видит информацию о заведении и баннер.
2. **Шаг 1:** В блоке «Отзыв шеф-повара» нажимает кнопку **«Забронировать стол»** или переходит через навигацию на страницу `reservation.html`.
3. **Шаг 2:** Ознакамливается с предупреждением (Bootstrap Alert) о подтверждении броней в пиковые часы.
4. **Шаг 3:** Заполняет форму бронирования: вводит имя, телефон, дату, время, количество гостей, выбирает зал (Основной / Терраса) и повод визита.
5. **End:** Нажимает кнопку **«Забронировать»** (`#booking-form`). Форма отправляется, и для JavaScript уже подготовлен контейнер `#booking-confirmation` для вывода подтверждения номера брони. При необходимости точного адреса нажимает в меню **«Контакты»** (`contacts.html`), где видит адрес «ул. Темирбека Жургенова, 18/1», телефон и схему работы с 12:00 до 02:00.

### 🚶 Journey 2: "Выбрать горячие блюда в меню и оформить доставку на дом"
1. **Start:** Посетитель открывает страницу `menu.html` через единую навигацию сайта.
2. **Шаг 1:** Просматривает раздел «Горячие блюда и Гриль» (`#hot`), изучает цены (Стейк Рибай 8 500 ₸, Баварские колбаски 3 200 ₸, Пицца Пепперони 3 500 ₸).
3. **Шаг 2:** Нажимает кнопку **«Заказать с доставкой →»**, которая напрямую переводит его на страницу доставки `order.html`.
4. **Шаг 3:** Изучает условия доставки по Астане (время 45–60 мин, бесплатная доставка от 7 000 ₸, 4 шага выполнения заказа).
5. **Шаг 4:** В форме оформления доставки выбирает основное блюдо (`#dishSelect`), количество порций, вводит контактные данные, дату и адрес доставки, выбирает способ оплаты (Kaspi QR / карта курьеру / наличные).
6. **End:** Нажимает кнопку **«Оформить доставку»** (`#order-form`). Данные фиксируются, и подготовленный блок `#order-confirmation` готов принять статус заказа от скрипта.

### 🚶 Journey 3: "Изучить отзывы гостей и оставить собственное впечатление"
1. **Start:** Посетитель переходит на страницу отзывов `feedback.html`.
2. **Шаг 1:** Видит агрегированный рейтинг заведения (5/5 на основе 16 оценок, прогресс-бары оценок) и реальные отзывы гостей с фотографиями блюд и интерьера.
3. **Шаг 2:** Нажимает кнопку **«✎ Оставить свой отзыв»**, открывающую интерактивную форму отзыва через нативный Bootstrap Collapse (`#reviewFormCollapse`).
4. **Шаг 3:** Выставляет оценку от 1 до 5, указывает достоинства, недостатки и пишет комментарий в поле с валидацией `required`.
5. **End:** Нажимает кнопку **«Отправить отзыв»** в фирменном цвете `btn-danger`. Форма завершает сценарий, а контейнер `#review-confirmation` готов отобразить благодарность за отзыв.

* **Единая шапка и футер:** Тёмный `header.container-fluid` и `footer.container-fluid` с единым копирайтом «Frau Muller © 2026».
* **Отсутствие мертвых ссылок:** Все ссылки ведут на реальные страницы или существующие якорные секции, ссылки `href="#"` полностью устранены.

## 3. CSS Architecture & Key Implementations

### A. Color Palette & Typography (`css/base.css`)
Defined at the root level with a strict maximum of 5 colors:
1. `#F5F2EB` (Light Parchment / Beige) — Main background ensuring readability and warmth.
2. `rgba(43, 30, 22, 1)` (Dark Wood) — Header and footer background reflecting traditional Bavarian pub aesthetics.
3. `#2C2C2C` (Charcoal) — Primary body text color, softer than pure black.
4. `DarkRed` (Named Color) — Accent color for borders, links, and highlights.
5. `#D4AF37` (Mustard / Antique Gold) — Interactive states (:hover, :focus, accents).

Typography features deliberate font stacks:
- Headings: `Georgia, "Times New Roman", serif`
- Body copy: `Arial, Helvetica, sans-serif`

### B. Selectors Coverage (All Required Types Used)
- **Type Selectors:** `h1, h2, h3`, `legend`, `p`, `table`, etc.
- **Class Selectors:** `.order-card`, `.colophon-grid`, `.step-item`, `.delivery-info`, `.price-tag`, etc.
- **ID Selectors:** `#order-form`, `#colophon-main`, `#history-section`, `#contact-main`.
- **Descendant Selectors:** `.order-form label`, `header h1`.
- **Child Selectors (`>`):** `fieldset > input[type="checkbox"]`, `.booking-form > fieldset`.
- **Adjacent Sibling Selectors (`+`):** `label + input[type="text"]`, `h2 + p`.
- **Grouping with Commas:** `button[type="submit"], button[type="reset"]`, `input, textarea`.
- **Attribute Selectors:** `input[type="tel"]`, `input[type="date"]`, `button[type="submit"]`.
- **Universal Selector (`*`):** Resetting box-sizing to `border-box`.
- **Pseudo-Classes:** `:hover`, `:focus`, `:first-child`.
- **Pseudo-Elements:** `::after`, `::before`.

### C. Layout Systems: Flexbox & Grid
1. **Flexbox:**
   - Global navigation row with `justify-content: center; align-items: center; gap: 20px;` in `css/base.css`.
   - Card rows with `flex-wrap: wrap; flex-direction: row;` and items that grow/shrink (`flex: 1 1 180px;`) on `order.html` (`.order-steps`, `.step-item`) and `contacts.html` (`#contact-main`, `.contact-card`).
2. **CSS Grid:**
   - Multi-column responsive layout on `colophon.html` (`.colophon-grid`) and `index.html` (`.main-grid`) using `repeat(auto-fit, minmax(280px, 1fr))` and `gap`.
   - Grid spanning element (`grid-column: 1 / -1;`) on `.grid-span-all` in `colophon.html`.

### D. Positioning, Float & Clear
1. **Positioning (all 4 values demonstrated):**
   - `static`: Document flow behavior explained on `.static-content` and `#history-section`.
   - `relative`: Containing block for badge on `.order-card-relative` and `.hero-article`.
   - `absolute`: Promo badge (`.promo-badge`) and image caption overlay (`.overlay-figure figcaption`).
   - `fixed`: Floating quick call / order button (`.fixed-order-btn`) remaining pinned to bottom-right during scroll.
2. **Float & Clear:**
   - Float left on `.float-img` with text wrapping around the image.
   - Proper clearance via `.delivery-clear { clear: both; }` preventing parent container collapse and overlap.

### E. 3 Distinct Centering Techniques
1. **Technique 1 (Margin Auto):** Horizontal centering of block containers with constrained width (`.center-block`, `main` in `base.css`).
2. **Technique 2 (Flexbox):** Two-axis centering using `display: flex; justify-content: center; align-items: center;` on `.center-flex-box`.
3. **Technique 3 (Absolute + Transform):** Dead-center positioning within relative container via `top: 50%; left: 50%; transform: translate(-50%, -50%);` on `.center-absolute-item`.

### F. Priority, Cascade & Specificity Experiments

## Log Entry 1: CSS Specificity and Cascade Calculation
* **Date:** 2026-09-20
* **Topic / Question Asked:**
  > "How is CSS specificity calculated for combined selectors such as `.order-badge` versus `span.order-badge`, and how does the browser resolve conflicts without using `!important`?"
* **Concept Clarification Received:**
  CSS specificity is represented as a tuple of components: `(Inline styles, ID selectors, Class/Attribute/Pseudo-class selectors, Type/Pseudo-element selectors)`.
  - `.order-badge` has 0 inline styles, 0 IDs, 1 class, and 0 type selectors $\rightarrow$ Specificity $(0, 1, 0)$.
  - `span.order-badge` has 0 inline styles, 0 IDs, 1 class, and 1 type selector (`span`) $\rightarrow$ Specificity $(0, 1, 1)$.
  Because $(0, 1, 1) > (0, 1, 0)$, the second rule takes precedence regardless of source order in the stylesheet. This resolves conflicts purely through selector weighting without resorting to `!important`.
* **Application in Project:**
  Implemented in `css/nurmuhammadjon.css` (lines 120–141) as the required Specificity Experiment targeting `.order-badge`.

---

## Log Entry 2: Margin Collapse in the Box Model
* **Date:** 2026-09-20
* **Topic / Question Asked:**
  > "Why does the bottom margin of an `<h2>` heading collapse into the top margin of the following `<fieldset>` or container element instead of adding up, and how should this be handled?"
* **Concept Clarification Received:**
  In CSS, adjoining vertical margins of block-level elements in the normal document flow collapse into a single margin whose size is equal to the maximum of the adjoining margins (or sum of positive and negative if mixed). This is known as **margin collapse** and only occurs in vertical orientation (never horizontal), and does not apply to flex or grid containers.
* **Application in Project:**
  Documented in `css/nurmuhammadjon.css` (lines 15–24) with explicit spacing strategy applied to `.order-section h2` and `.order-form`.

---

## Log Entry 3: Float Mechanics and the Clear Property
* **Date:** 2026-09-21
* **Topic / Question Asked:**
  > "What exactly happens to the containing parent and subsequent block elements when an image is floated with `float: left;`, and why is `clear: both;` necessary?"
* **Concept Clarification Received:**
  When an element is floated, it is taken out of normal block flow while inline content continues to wrap around it. If the containing block only holds the floated element or if subsequent block elements are rendered, the parent container collapses in height (zero-height collapse), and following non-floated headings or forms will slip behind or awkwardly wrap around the floated image. Applying `clear: both;` (or a clearfix) creates an clearance above the cleared element, forcing the parent to encapsulate the float and restoring standard document flow.
* **Application in Project:**
  Implemented on `order.html` around `<img>` and styled in `css/nurmuhammadjon.css` (lines 318–332) with a `.delivery-clear` element.

---

## Log Entry 4: Comparative Analysis of Centering Techniques
* **Date:** 2026-09-21
* **Topic / Question Asked:**
  > "What are the core technical differences and appropriate use cases for horizontal centering with `margin: 0 auto;`, two-axis centering with Flexbox (`justify-content` / `align-items`), and absolute positioning with `transform: translate(-50%, -50%)`?"
* **Concept Clarification Received:**
  1. **`margin: 0 auto;`**: Operates on block-level elements with an explicit or constrained width (`max-width`). It distributes remaining horizontal space equally to left and right margins. Ideal for main layout containers and form wrappers.
  2. **Flexbox Centering**: `justify-content: center; align-items: center;` operates on a flex container to align children along both the main axis and cross axis. Ideal for dynamic content, buttons, banners, and card headers.
  3. **Absolute Positioning + Transform**: `top: 50%; left: 50%; transform: translate(-50%, -50%);` positions the element relative to its nearest positioned ancestor. The percentage in `transform` is calculated relative to the element's *own* dimensions, enabling centering without knowing its width or height in advance.
* **Application in Project:**
  All three distinct methods were demonstrated with explanatory comments in `css/nurmuhammadjon.css` (lines 338–374) and applied on `order.html`.

---

## Log Entry 5: Architectural Choice — CSS Grid vs. Flexbox
* **Date:** 2026-09-21
* **Topic / Question Asked:**
  > "How to justify choosing CSS Grid over Flexbox for a technical specification and role overview page?"
* **Concept Clarification Received:**
  Flexbox is fundamentally **one-dimensional** (lays items along either a row or a column, wrapping only as an overflow mechanism where each row calculates widths independently). CSS Grid is **two-dimensional**, governing both rows and columns simultaneously. Grid is superior when elements must align with one another across both axes, such as multi-column specification cards (`.colophon-grid`) and spanning summary blocks (`grid-column: 1 / -1`).
* **Application in Project:**
  Implemented on `colophon.html` using `.colophon-grid` with `repeat(auto-fit, minmax(280px, 1fr))` and spanning item `.grid-span-all`, detailed in `css/nurmuhammadjon.css` (lines 66–75, 377–383).

## Log Entry 1: Mobile-First 12-Column Grid Architecture and Breakpoints
* **Date:** 2026-10-01
* **Topic / Question Asked:**
  > "How does Bootstrap 5 calculate column widths across different viewports (mobile-first approach), and how do classes like `col-12 col-md-6 col-lg-3` cascade upwards through breakpoints?"
* **Concept Clarification Received:**
  Bootstrap uses a mobile-first `min-width` media query approach. The base class `col-12` applies to all viewport widths from $0\text{px}$ up (`xs`). When the viewport reaches $768\text{px}$ (`md`), the `col-md-6` rule overrides the base, giving $50\%$ width ($6/12$). At $992\text{px}$ (`lg`), `col-lg-3` takes precedence, setting each item to $25\%$ ($3/12$). This ensures smooth responsive adaptation from single-column on mobile to multi-column on desktop without custom media queries.
* **Application in Project:**

## Log Entry 2: Container vs. Container-Fluid Design Principles
* **Date:** 2026-10-01
* **Topic / Question Asked:**
  > "When is it semantically and visually appropriate to choose `.container-fluid` over standard `.container` in modern web layouts?"
* **Concept Clarification Received:**
  `.container-fluid` maintains `width: 100%` across all viewport sizes, making it ideal for full-bleed hero banners, top-level navigation bars, and footers where background colors must stretch edge-to-edge. Conversely, `.container` applies predefined responsive `max-width` thresholds at each breakpoint, centering the grid (`margin-left: auto; margin-right: auto;`) with comfortable reading margins.
* **Application in Project:**
  Demonstrated on both `order.html` and `colophon.html`: `<header class="container-fluid">` and `<footer class="container-fluid">` span $100\%$ width with dark wood background, while `<main class="container">` contains the central content grid.

## Log Entry 3: Nested Grids and Gutters Management
* **Date:** 2026-10-02
* **Topic / Question Asked:**
  > "How do nested `.row` elements inside a `.col-*` handle margin-padding offsets, and why are gutter classes like `.g-3` preferred over manual margins?"
* **Concept Clarification Received:**
  Bootstrap `.row` elements apply negative horizontal margins (e.g. `-0.75rem`) to counteract the padding of parent column containers. When nesting a `.row` inside a `.col-*`, Bootstrap automatically aligns child columns to the grid boundaries without overflowing. Using `.g-3` sets consistent horizontal and vertical gaps via CSS variables (`--bs-gutter-x`, `--bs-gutter-y`), eliminating manual margin overrides.
* **Application in Project:**
  Implemented in the right-hand column of `order.html` (`.col-12 .col-lg-5`), where a nested `<div class="row g-3">` creates dual delivery metric badges.

## Log Entry 4: Navbar Collapse Mechanics and Accessibility (ARIA)
* **Date:** 2026-10-02
* **Topic / Question Asked:**
  > "What JavaScript data attributes and ARIA roles are required for the Bootstrap navbar toggler button to properly collapse and expand on mobile screens?"
* **Concept Clarification Received:**
  Bootstrap 5 uses pure JavaScript without jQuery. The toggler button requires `data-bs-toggle="collapse"` and `data-bs-target="#mainNav"`. For accessibility, `aria-controls="mainNav"`, `aria-expanded="false"`, and `aria-label="Toggle navigation"` must be provided. The target container requires `.collapse .navbar-collapse` with matching `id="mainNav"`.
* **Application in Project:**

## Log Entry 5: Custom CSS Reduction and Component Adaptation
* **Date:** 2026-10-02
* **Topic / Question Asked:**
  > "How to systematically identify and remove redundant CSS when migrating an existing site to Bootstrap 5 while preserving brand identity?"
* **Concept Clarification Received:**
  Any custom rule defining display mode (`flex`, `grid`), column widths, padding, margins, borders, button states, or form sizing can be replaced with native Bootstrap classes (`.d-flex`, `.row`, `.p-4`, `.btn`, `.form-control`). The remaining custom stylesheet should act strictly as a brand palette and typography layer (`< 50` lines), only overriding CSS variables or adding brand-specific accents.

'use strict';

/**
 * Checks current time and updates live open/closed status badge
 */
function initLiveOpenStatus() {
    const statusContainer = document.getElementById('live-restaurant-status');
    if (!statusContainer) {
        return;
    }

    const now = new Date();
    const hour = now.getHours();

    // Resto-pub Frau Muller operates from 12:00 PM to 02:00 AM (next day)
    const isOpen = hour >= 12 || hour < 2;

    statusContainer.textContent = '';

    const badge = document.createElement('span');
    badge.className = isOpen
        ? 'badge bg-success p-2 fs-6 shadow-sm d-inline-flex align-items-center gap-2'
        : 'badge bg-secondary p-2 fs-6 shadow-sm d-inline-flex align-items-center gap-2';

    const dot = document.createElement('span');
    dot.className = isOpen ? 'spinner-grow spinner-grow-sm text-light' : 'd-none';
    dot.setAttribute('role', 'status');

    const text = document.createTextNode(isOpen ? 'Сейчас открыто: ждём вас до 02:00' : 'Сейчас закрыто: открываемся в 12:00');

    badge.appendChild(dot);
    badge.appendChild(text);
    statusContainer.appendChild(badge);
}

/**
 * Initializes callback and manager message form
 */
function initCallbackForm() {
    const form = document.getElementById('contacts-callback-form');
    const msgContainer = document.getElementById('callback-message-container');

    if (!form) {
        return;
    }

    form.addEventListener('submit', function (event) {
        event.preventDefault();

        const nameInput = document.getElementById('cb-name');
        const phoneInput = document.getElementById('cb-phone');
        const topicSelect = document.getElementById('cb-topic');
        const messageInput = document.getElementById('cb-message');

        const nameVal = nameInput ? nameInput.value.trim() : '';
        const phoneVal = phoneInput ? phoneInput.value.trim() : '';
        const topicVal = topicSelect ? topicSelect.options[topicSelect.selectedIndex].text : 'Общий вопрос';
        const messageVal = messageInput ? messageInput.value.trim() : '';

        if (nameVal.length < 2) {
            nameInput.classList.add('is-invalid');
            nameInput.focus();
            return;
        }
        nameInput.classList.remove('is-invalid');

        const cleanedDigits = phoneVal.replace(/\D/g, '');
        if (cleanedDigits.length < 10) {
            phoneInput.classList.add('is-invalid');
            phoneInput.focus();
            return;
        }
        phoneInput.classList.remove('is-invalid');

        if (msgContainer) {

/**

 * Assignment 4-5: Dynamic Review Filtering, Sorting & Submission

'use strict';

/**
 * Initializes review filters, sorting controls, and dynamic submission
 */
function initFeedbackInteractivity() {
    const reviewsContainer = document.getElementById('reviews-container');
    const starFiltersContainer = document.getElementById('star-filters');
    const sortDateBtn = document.getElementById('sort-date');
    const sortRatingBtn = document.getElementById('sort-rating');
    const sortUsefulnessBtn = document.getElementById('sort-usefulness');
    const feedbackForm = document.getElementById('feedback-form');
    const feedbackMessageContainer = document.getElementById('feedback-message-container');

    if (!reviewsContainer) {
        return;
    }

    let activeFilter = 'all';
    let currentSort = 'date';
    let sortDirection = 'desc';

    // 1. Star Filters
    if (starFiltersContainer) {
        const filterButtons = starFiltersContainer.querySelectorAll('.filter-btn');

        filterButtons.forEach(function (btn) {
            btn.style.cursor = 'pointer';
            btn.addEventListener('click', function () {
                activeFilter = btn.getAttribute('data-filter') || 'all';

                filterButtons.forEach(function (b) {
                    b.classList.remove('active-filter', 'text-dark', 'border-bottom', 'border-2', 'border-dark', 'pb-1');
                    b.classList.add('text-muted');
                });

                btn.classList.remove('text-muted');
                btn.classList.add('active-filter', 'text-dark', 'border-bottom', 'border-2', 'border-dark', 'pb-1');

                applyFiltersAndSort();
            });
        });
    }

    // 2. Sorting Controls
    function updateSortButtonsUI(activeBtn, labelText) {
        [sortDateBtn, sortRatingBtn, sortUsefulnessBtn].forEach(function (btn) {
            if (btn) {
                btn.classList.remove('text-dark', 'fw-bold', 'border-bottom', 'border-dark');
                btn.classList.add('text-muted');
            }
        });

        if (activeBtn) {
            activeBtn.classList.remove('text-muted');
            activeBtn.classList.add('text-dark', 'fw-bold', 'border-bottom', 'border-dark');
            const arrow = sortDirection === 'desc' ? ' ↓' : ' ↑';
            activeBtn.textContent = labelText + arrow;
        }
    }

    if (sortDateBtn) {
        sortDateBtn.addEventListener('click', function () {
            if (currentSort === 'date') {
                sortDirection = sortDirection === 'desc' ? 'asc' : 'desc';
            } else {
                currentSort = 'date';
                sortDirection = 'desc';
            }
            updateSortButtonsUI(sortDateBtn, 'Дате');
            applyFiltersAndSort();
        });
    }

    if (sortRatingBtn) {
        sortRatingBtn.addEventListener('click', function () {
            if (currentSort === 'rating') {
                sortDirection = sortDirection === 'desc' ? 'asc' : 'desc';
            } else {
                currentSort = 'rating';
                sortDirection = 'desc';
            }
            updateSortButtonsUI(sortRatingBtn, 'Рейтингу');
            applyFiltersAndSort();
        });
    }

    if (sortUsefulnessBtn) {
        sortUsefulnessBtn.addEventListener('click', function () {
            if (currentSort === 'usefulness') {
                sortDirection = sortDirection === 'desc' ? 'asc' : 'desc';
            } else {
                currentSort = 'usefulness';
                sortDirection = 'desc';
            }
            updateSortButtonsUI(sortUsefulnessBtn, 'Полезности');
            applyFiltersAndSort();
        });
    }

    /**
     * Reorders and toggles visibility of review cards based on active filter and sort state
     */
    function applyFiltersAndSort() {
        const cards = Array.from(reviewsContainer.querySelectorAll('.review-card'));
        let visibleCount = 0;

        // Sort cards
        cards.sort(function (a, b) {
            let valA = 0;
            let valB = 0;

            if (currentSort === 'date') {
                const dateA = a.getAttribute('data-date') || '2026-01-01';
                const dateB = b.getAttribute('data-date') || '2026-01-01';
                return sortDirection === 'desc' ? dateB.localeCompare(dateA) : dateA.localeCompare(dateB);
            }

            if (currentSort === 'rating') {
                valA = parseInt(a.getAttribute('data-rating') || '0', 10);
                valB = parseInt(b.getAttribute('data-rating') || '0', 10);
            } else if (currentSort === 'usefulness') {
                valA = parseInt(a.getAttribute('data-usefulness') || '0', 10);
                valB = parseInt(b.getAttribute('data-usefulness') || '0', 10);
            }

            return sortDirection === 'desc' ? valB - valA : valA - valB;
        });

        // Filter cards and re-append in sorted order
        cards.forEach(function (card) {
            const cardRating = card.getAttribute('data-rating');
            const isMatch = activeFilter === 'all' || cardRating === activeFilter;

            if (isMatch) {
                card.classList.remove('d-none');
                visibleCount++;
            } else {
                card.classList.add('d-none');
            }

            reviewsContainer.appendChild(card);
        });

        // Empty state check
        let emptyMsg = reviewsContainer.querySelector('#empty-reviews-alert');
        if (visibleCount === 0) {
            if (!emptyMsg) {
                emptyMsg = document.createElement('div');
                emptyMsg.id = 'empty-reviews-alert';
                emptyMsg.className = 'alert alert-info text-center py-4 my-3';
                emptyMsg.textContent = 'Отзывов с такой оценкой пока нет. Вы можете стать первым!';
                reviewsContainer.appendChild(emptyMsg);
            }
        } else if (emptyMsg) {
            emptyMsg.remove();
        }
    }

    // 3. New Review Submission
    if (feedbackForm) {
        feedbackForm.addEventListener('submit', function (event) {
            event.preventDefault();

            const ratingInput = document.getElementById('feedback-rating');
            const prosInput = document.getElementById('feedback-pros');
            const consInput = document.getElementById('feedback-cons');
            const commentInput = document.getElementById('feedback-comment');

            const ratingVal = parseInt(ratingInput.value, 10);
            const prosVal = prosInput.value.trim();
            const consVal = consInput.value.trim();
            const commentVal = commentInput.value.trim();

            if (isNaN(ratingVal) || ratingVal < 1 || ratingVal > 5) {
                ratingInput.classList.add('is-invalid');
                ratingInput.focus();
                return;
            }
            ratingInput.classList.remove('is-invalid');

            if (commentVal.length < 5) {
                commentInput.classList.add('is-invalid');
                commentInput.focus();
                return;
            }
            commentInput.classList.remove('is-invalid');

            // Format current date: DD.MM.YYYY
            const now = new Date();
            const dayStr = String(now.getDate()).padStart(2, '0');
            const monthStr = String(now.getMonth() + 1).padStart(2, '0');
            const yearStr = now.getFullYear();
            const formattedDate = dayStr + '.' + monthStr + '.' + yearStr;
            const isoDate = yearStr + '-' + monthStr + '-' + dayStr;

            // Generate star string
            let starsStr = '';
            for (let i = 0; i < 5; i++) {
                starsStr += i < ratingVal ? '★ ' : '☆ ';
            }

            // Create new review card safely via DOM
            const newCard = document.createElement('div');
            newCard.className = 'card border-0 shadow-sm rounded-0 mb-3 review-card border-top border-success border-3';
            newCard.setAttribute('data-rating', String(ratingVal));
            newCard.setAttribute('data-date', isoDate);
            newCard.setAttribute('data-usefulness', '1');

            const cardBody = document.createElement('div');
            cardBody.className = 'card-body';

            const headerRow = document.createElement('div');
            headerRow.className = 'd-flex justify-content-between align-items-center mb-3';

            const userLeft = document.createElement('div');
            userLeft.className = 'd-flex align-items-center';

            const avatar = document.createElement('div');
            avatar.className = 'bg-success rounded-circle d-flex justify-content-center align-items-center text-white me-3';
            avatar.style.width = '40px';
            avatar.style.height = '40px';
            avatar.textContent = 'Г';

            const userMeta = document.createElement('div');
            const nameSpan = document.createElement('span');
            nameSpan.className = 'fw-bold me-2';
            nameSpan.textContent = 'Гость сайта';

            const starsSpan = document.createElement('span');
            starsSpan.className = 'text-danger me-2';
            starsSpan.textContent = starsStr.trim();

            const dateSpan = document.createElement('span');
            dateSpan.className = 'text-muted small';
            dateSpan.textContent = ' ' + formattedDate;

            userMeta.appendChild(nameSpan);
            userMeta.appendChild(starsSpan);
            userMeta.appendChild(dateSpan);

            userLeft.appendChild(avatar);
            userLeft.appendChild(userMeta);

            const badge = document.createElement('span');
            badge.className = 'badge bg-success small';
            badge.textContent = 'Новый отзыв';

            headerRow.appendChild(userLeft);
            headerRow.appendChild(badge);

            const commentHeading = document.createElement('p');
            commentHeading.className = 'fw-bold mb-1';
            commentHeading.textContent = 'Комментарий:';

            const commentP = document.createElement('p');
            commentP.className = 'text-muted small mb-0';
            commentP.textContent = commentVal;

            cardBody.appendChild(headerRow);

            if (prosVal || consVal) {
                const table = document.createElement('table');
                table.className = 'table table-borderless table-sm mb-3';
                const tbody = document.createElement('tbody');

                if (prosVal) {
                    const trPros = document.createElement('tr');
                    const tdLabel = document.createElement('td');
                    tdLabel.className = 'fw-bold text-success';
                    tdLabel.style.width = '120px';
                    tdLabel.textContent = 'Достоинства';
                    const tdVal = document.createElement('td');
                    tdVal.className = 'text-success';
                    tdVal.textContent = prosVal;
                    trPros.appendChild(tdLabel);
                    trPros.appendChild(tdVal);
                    tbody.appendChild(trPros);
                }

                if (consVal) {
                    const trCons = document.createElement('tr');
                    const tdLabel = document.createElement('td');
                    tdLabel.className = 'fw-bold text-danger';
                    tdLabel.style.width = '120px';
                    tdLabel.textContent = 'Недостатки';
                    const tdVal = document.createElement('td');
                    tdVal.className = 'text-danger';
                    tdVal.textContent = consVal;
                    trCons.appendChild(tdLabel);
                    trCons.appendChild(tdVal);
                    tbody.appendChild(trCons);
                }

                table.appendChild(tbody);
                cardBody.appendChild(table);
            }

            cardBody.appendChild(commentHeading);
            cardBody.appendChild(commentP);
            newCard.appendChild(cardBody);

            // Prepend new card to container
            reviewsContainer.insertBefore(newCard, reviewsContainer.firstChild);

            // Show success feedback
            if (feedbackMessageContainer) {
                feedbackMessageContainer.textContent = '';
                const alert = document.createElement('div');
                alert.className = 'alert alert-success py-2 small';
                alert.textContent = 'Спасибо за ваш отзыв! Он успешно добавлен и отображается в списке.';
                feedbackMessageContainer.appendChild(alert);
            }

            feedbackForm.reset();
            applyFiltersAndSort();
        });
    }
}

/**
 * Reusable function 1: Formats number into KZT currency string
 * @param {number} amount - Numeric price
 * @returns {string} Formatted string with currency sign
 */
function formatCurrency(amount) {
    return amount.toLocaleString('ru-RU') + ' ₸';
}

/**
 * Reusable function 2: Calculates discounted price with percentage
 * @param {number} originalPrice - Base price
 * @param {number} discountPercent - Discount percent (e.g. 15)
 * @returns {number} Final discounted price rounded to nearest 50
 */
function calculateDiscountPrice(originalPrice, discountPercent) {
    const rawDiscounted = originalPrice * (1 - discountPercent / 100);
    return Math.round(rawDiscounted / 50) * 50;
}

/**
 * Validates password strength according to security checklist
 * @param {string} password - Raw password input
 * @returns {Object} Validation states for each rule
 */
function validatePasswordRules(password) {
    const minLength = 8;
    const hasUpper = /[A-ZА-ЯЁ]/.test(password);
    const hasLower = /[a-zа-яё]/.test(password);
    const hasDigit = /[0-9]/.test(password);
    const hasSpecial = /[!@#$%^&*()_+\-=\[\]{};':"\\|,.<>\/?]/.test(password);
    const isLengthValid = password.length >= minLength;

    const allPassed = isLengthValid && hasUpper && hasLower && hasDigit && hasSpecial;

    return {
        isLengthValid,
        hasUpper,
        hasLower,
        hasDigit,
        hasSpecial,
        allPassed
    };
}

'use strict';

/**
 * Global Cart State for Menu
 */
const MenuCart = {
    items: {},

    load() {
        try {
            const saved = localStorage.getItem('fraumuller_cart');
            if (saved) {
                this.items = JSON.parse(saved);
            }
        } catch (e) {
            this.items = {};
        }
    },

    save() {
        try {
            localStorage.setItem('fraumuller_cart', JSON.stringify(this.items));
        } catch (e) {
            // LocalStorage fallback
        }
    },

    addItem(name, price, image) {
        if (!this.items[name]) {
            this.items[name] = { name: name, price: price, qty: 1, image: image || '' };
        } else {
            this.items[name].qty += 1;
        }
        this.save();
    },

    removeItem(name) {
        if (this.items[name]) {
            this.items[name].qty -= 1;
            if (this.items[name].qty <= 0) {
                delete this.items[name];
            }
            this.save();
        }
    },

    clear() {
        this.items = {};
        this.save();
    },

    getTotalPrice() {
        let total = 0;
        for (const key in this.items) {
            if (Object.prototype.hasOwnProperty.call(this.items, key)) {
                total += this.items[key].price * this.items[key].qty;
            }
        }
        return total;
    },

    getTotalCount() {
        let count = 0;
        for (const key in this.items) {
            if (Object.prototype.hasOwnProperty.call(this.items, key)) {
                count += this.items[key].qty;
            }
        }
        return count;
    }
};

/**

 */
function initMenuSearch() {
    const searchInput = document.getElementById('menu-search-input');
    const clearBtn = document.getElementById('menu-search-clear');
    const resultsInfo = document.getElementById('search-results-info');

    if (!searchInput) {
        return;
    }

    function doSearch() {
        const query = searchInput.value.toLowerCase().trim();
        const rows = document.querySelectorAll('tbody tr[data-dish-name]');
        let matchCount = 0;

        rows.forEach(function (row) {
            const name = row.getAttribute('data-dish-name') || '';
            const desc = row.getAttribute('data-dish-desc') || '';

            if (query === '' || name.includes(query) || desc.includes(query)) {
                row.classList.remove('d-none');
                matchCount++;
            } else {
                row.classList.add('d-none');
            }
        });

        // Hide empty sections
        const sections = document.querySelectorAll('section.card');
        sections.forEach(function (sec) {
            const visibleRows = sec.querySelectorAll('tbody tr:not(.d-none)');
            if (visibleRows.length === 0 && query !== '') {
                sec.classList.add('d-none');
            } else {
                sec.classList.remove('d-none');
            }
        });

        // Update info text
        if (resultsInfo) {
            if (query !== '') {
                resultsInfo.classList.remove('d-none');
                resultsInfo.textContent = 'Найдено позиций: ' + matchCount;
            } else {
                resultsInfo.classList.add('d-none');
            }
        }
    }

    searchInput.addEventListener('input', doSearch);

    if (clearBtn) {
        clearBtn.addEventListener('click', function () {
            searchInput.value = '';
            doSearch();
            searchInput.focus();
        });
    }
}

/**
 * Reusable function 1: Formats number into KZT currency string
 * @param {number} amount - Numeric sum
 * @returns {string} Formatted string
 */
function formatKzt(amount) {
    return amount.toLocaleString('ru-RU') + ' ₸';
}

/**
 * Reusable function 2: Generates a temporary booking reference number using Math.random()
 * @returns {string} Unique demo code like "FM-7342"
 */
function generateBookingReference() {
    const randomDigits = Math.floor(1000 + Math.random() * 9000);
    return 'FM-' + randomDigits;
}

/**
 * Reusable function 3: Evaluates date for weekend status, holidays and table load
 * @param {string} dateString - "YYYY-MM-DD"
 * @returns {Object} Schedule information
 */
function checkDateSchedule(dateString) {
    if (!dateString) {
        return { isWeekend: false, holidayName: null, occupancyStatus: 'Обычная загрузка' };
    }

    const dateObj = new Date(dateString + 'T00:00:00');
    const dayOfWeek = dateObj.getDay(); // 0 is Sunday, 5 is Friday, 6 is Saturday
    const isWeekend = dayOfWeek === 5 || dayOfWeek === 6;

    const monthDay = dateString.slice(5); // "MM-DD"
    const holidayName = KZ_HOLIDAYS[monthDay] || null;

    let occupancyStatus = 'Свободных столиков достаточно (~75% доступно)';
    let alertClass = 'alert-info';

    if (holidayName) {
        occupancyStatus = 'Праздничный день: столы бронируются быстрее обычного (~20% свободно)';
        alertClass = 'alert-warning';
    } else if (isWeekend) {
        occupancyStatus = 'Пятница/Выходной: пиковые часы (~35% свободно, подтверждение до 15 мин)';
        alertClass = 'alert-warning';
    }

    return {
        isWeekend,
        holidayName,
        occupancyStatus,
        alertClass
    };
}

/**
 * Reusable function 4: Calculates required reservation deposit and surcharges
 * Includes group discounts and birthday special bonuses
 * @param {number} guestCount - Number of visitors
 * @param {string} zone - Selected hall zone ('main', 'terrace', 'vip')
 * @param {string} dateString - "YYYY-MM-DD"
 * @param {string} occasion - 'dinner', 'birthday', or 'corporate'
 * @returns {Object} Full calculation breakdown
 */
function calculateBookingDeposit(guestCount, zone, dateString, occasion) {
    const basePerGuest = 2000;
    const guestTotal = guestCount * basePerGuest;

    let zoneSurcharge = 0;
    let zoneName = 'Основной зал';

    if (zone === 'vip') {
        zoneSurcharge = 5000;
        zoneName = 'VIP кабина (приватная лаунж-зона)';
    } else if (zone === 'terrace') {
        zoneSurcharge = 1000;
        zoneName = 'Летняя терраса';
    }

    const scheduleInfo = checkDateSchedule(dateString);
    const subtotal = guestTotal + zoneSurcharge;
    const weekendMultiplier = scheduleInfo.isWeekend ? 0.1 : 0;
    const weekendSurcharge = Math.round(subtotal * weekendMultiplier);

    // Group size discount: 10% for 10+ guests, 5% for 6+ guests
    let groupDiscountPercent = 0;
    if (guestCount >= 10) {
        groupDiscountPercent = 10;
    } else if (guestCount >= 6) {
        groupDiscountPercent = 5;
    }
    const groupDiscountAmount = Math.round(subtotal * (groupDiscountPercent / 100));

    // Birthday bonus: 10% discount on booking + chef's surprise gift
    let birthdayDiscountAmount = 0;
    let birthdayGift = null;
    if (occasion === 'birthday') {
        birthdayDiscountAmount = Math.round(subtotal * 0.1);
        birthdayGift = '🎂 Фирменный мини-торт «Захер» со свечой от шеф-повара (в подарок)';
    }

    const totalDiscounts = groupDiscountAmount + birthdayDiscountAmount;
    const finalDeposit = Math.max(1000, subtotal + weekendSurcharge - totalDiscounts);

    return {
        guestCount,
        basePerGuest,
        guestTotal,
        zoneName,
        zoneSurcharge,
        isWeekend: scheduleInfo.isWeekend,
        holidayName: scheduleInfo.holidayName,
        weekendSurcharge,
        groupDiscountPercent,
        groupDiscountAmount,
        birthdayDiscountAmount,
        birthdayGift,
        finalDeposit
    };
}

/**
 * Validates a single field according to specific rules
 * @param {string} fieldName - Field identifier
 * @param {HTMLFormElement} form - Form reference
 * @returns {string|null} Error string if invalid, or null if valid
 */
function validateBookingField(fieldName, form) {
    const fullNameInput = form.querySelector('#fullName');
    const phoneInput = form.querySelector('#phoneNumber');
    const dateInput = form.querySelector('#resDate');
    const timeInput = form.querySelector('#resTime');
    const guestsInput = form.querySelector('#guestCount');
    const zoneSelect = form.querySelector('#zone');

    const todayStr = new Date().toISOString().split('T')[0];

    if (fieldName === 'fullName') {
        const val = fullNameInput.value.trim();
        if (val.length === 0) {
            return 'Пожалуйста, укажите ваше имя.';
        }
        if (val.length < 2) {
            return 'Имя должно содержать не менее 2 символов.';
        }
        const nameRegex = /^[A-Za-zА-Яа-яЁёӘәҒғҚқҢңӨөҰұҮүҺһІі\s\-]+$/;
        if (!nameRegex.test(val)) {
            return 'Имя может содержать только буквы, пробелы и дефисы.';
        }
        return null;
    }

    if (fieldName === 'phoneNumber') {
        const val = phoneInput.value.trim();
        if (val.length === 0) {
            return 'Пожалуйста, введите номер телефона.';
        }
        const cleanedDigits = val.replace(/\D/g, '');
        if (cleanedDigits.length < 10 || cleanedDigits.length > 12) {
            return 'Введите корректный номер (например, +7 778 777 00 03).';
        }
        return null;
    }

    if (fieldName === 'resDate') {
        const val = dateInput.value;
        if (!val) {
            return 'Выберите дату визита.';
        }
        if (val < todayStr) {
            return 'Дата визита не может быть в прошлом.';
        }
        const maxDate = new Date();
        maxDate.setDate(maxDate.getDate() + 60);
        const maxDateStr = maxDate.toISOString().split('T')[0];
        if (val > maxDateStr) {
            return 'Бронирование доступно максимум на 60 дней вперед.';
        }
        return null;
    }

    if (fieldName === 'resTime') {
        const val = timeInput.value;
        if (!val) {
            return 'Выберите время визита.';
        }
        const timeParts = val.split(':');
        const hour = parseInt(timeParts[0], 10);

        if (hour >= 2 && hour < 12) {
            return 'Ресто-паб работает с 12:00 дня до 02:00 ночи. Пожалуйста, выберите рабочее время.';
        }
        return null;
    }

    if (fieldName === 'guestCount') {
        const val = parseInt(guestsInput.value, 10);
        if (isNaN(val) || val < 1) {
            return 'Минимальное количество гостей — 1.';
        }
        if (val > 15) {
            return 'Для компании более 15 человек свяжитесь с нами по телефону.';
        }

        if (zoneSelect.value === 'vip' && val < 4) {
            return 'Бронирование VIP кабины доступно для компаний от 4 гостей.';
        }
        return null;
    }

    return null;
}
