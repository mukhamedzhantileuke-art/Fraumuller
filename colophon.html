Технические стандарты

Весь сайт построен строго на семантическом HTML5 и нативном CSS3 без использования сторонних CSS-фреймворков (таких как Bootstrap или Tailwind) и без скриптов JavaScript.

В коде строго соблюдена семантическая иерархия тегов: header, nav, main, section, article, aside, footer. Все страницы валидируются через W3C Validator с результатом: 0 errors.

Для обновления страницы и сброса кеша браузера используйте сочетание клавиш Ctrl + F5.

Архитектура стилей CSS

Стилизация проекта разделена на общекомандный базовый файл css/base.css, содержащий палитру из 5 цветов, типографику и оформление общих блоков (шапка, навигация, футер), а также персональные таблицы стилей каждого студента.
