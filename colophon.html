Технические стандарты (Assignment 3)

Архитектура Bootstrap 5.3

  • Сетка Grid System: 12 колонок, Flexbox
  • Поддерживаемые контрольные точки: 375px, 768px, 992px+
  • Горизонтальный скролл на 375px: Отсутствует (0 overflow)
  • Слой собственного CSS: < 50 строк на файл

Все ручные правила сетки, отступов и выравнивания из Assignment 2 заменены на нативные утилитные классы Bootstrap.

Подключение компонентов

Подключение стилей и скриптов осуществляется централизованно через CDN jsDelivr: 

<!-- Bootstrap 5.3.3 CSS & JS -->
<link href="https://cdn.../bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.../bootstrap.bundle.min.js"></script>

Для сброса кеша браузера и принудительного обновления стилей используйте Ctrl + F5.

Сводка адаптивности по контрольным точкам

Устройство Ширина окна Поведение сетки Навигация
Смартфон ≤ 576px (тест 375px) Колонки col-12 в одну вертикальную линию, 0 скролла Свернута в гамбургер-кнопку (Navbar Toggler)
Планшет ≥ 768px (тест 768px) Двухколоночная сетка (col-md-6, col-md-4) Свернута или компактный режим
Десктоп ≥ 992px (Desktop) Полноразмерная сетка (col-lg-7 / col-lg-5, col-lg-3) Полностью развернутая горизонтальная панель
